# ЖапырақСкан AI (2-нұсқа)

Жапырақ суреті бойынша өсімдік түрін, ауруларын (саңырауқұлақ, бактерия, вирус), су мен қоректік заттың жетіспеуін анықтайтын қазақ тіліндегі веб-платформа. Платформа тек өсімдік ауруларын зерттейді.

Автор: Болат Аделья, Е. Бозғұлов атындағы №249 мектеп-лицейі (Қазалы ауданы, Қызылорда облысы)
Ғылыми жетекші: Сараман Гүлдана Жанболатқызы

## Платформа қалай жұмыс істейді: үш тексеру

1. **AI көру модулі** (Google Gemini, қосымша Pl@ntNet). Өсімдіктің түрін (мәдени, көкөніс, жеміс, бөлме өсімдігі, арамшөп, улы өсімдік т.б.), ауруды, су мен қоректік заттың жетіспеуін атайды. Әр қорытындыға суретте не көрінгенін дәлел ретінде жазады.
2. **Түс индикаторы** телефонның өзінде, интернетсіз жұмыс істейді: жапырақты фоннан бөледі, әр нүктені түсіне қарай топтайды (сау, сарғайған, қураған, қара, тат түсті, ақ өңез, күлгін, сұр), денсаулық индексін (0–100) есептейді және «Белгілер картасын» салады.
3. **Анықтағыш кілт** – 9 сұрақтан тұратын тармақталған кілт. Сұрақтарға жауап бере отырып себепті нақтылайды. Интернетсіз де жұмыс істейді.

Екі тексеру бір белгіні көрсетсе, платформа «қорытындыға сенуге болады» дейді. Сәйкес келмесе, анықтағышпен тексеруді ұсынады.

## Білім қоры

- 76 өсімдік: дәнді, көкөніс, бақша, жеміс-жидек, техникалық, мал азықтық, ағаш-бұта, бөлме өсімдігі, сәндік гүл, дәрілік, арамшөп, улы өсімдік (Қызылорда өңірінің өсімдіктері де бар: күріш, қауын, жиде, сексеуіл, тораңғы, жыңғыл, адыраспан).
- 42 ауру мен физиологиялық бұзылыс: саңырауқұлақ, бактерия, вирус аурулары; азот, фосфор, калий, магний, темір, кальций тапшылығы; су тапшылығы, артық суару, күн күйігі, суық, тұздану, құрғақ ауа, жарық жетіспеуі, гербицид әсері.
- Әр жазбада дереккөз көрсетілген. Суреттер Уикипедиядан (Wikimedia Commons) автоматты жүктеледі.

## Файлдар

Барлық файл бір жерде тұрады, тек сервер функциялары `api` папкасында:

```
index.html        басты бет
style.css         безендіру
icon.svg          белгіше
analyzer.js       түс индикаторы (жапырақты бөлу, түс бойынша топтау, ережелер)
kb_plants.js      өсімдіктер каталогы
kb_disorders.js   аурулар мен бұзылыстар
kb_sources.js     дереккөздер тізімі
kb_key.js         анықтағыш кілт
samples.js        үлгі жапырақтар (суретсіз сынап көру үшін)
leaf_sets.js      салыстыру жиынтығы (100 сурет) және анықтамалықтың үлгі суреттері (128)
ref_images.js, test_images.js – PlantVillage және PlantDoc суреттері
compare.js        салыстырмалы зерттеу беті
app.js            интерфейс
api/analyze.js    AI көру модулі (Vercel сервер функциясы)
api/status.js     AI кілттерінің бапталғанын тексеру
vercel.json, package.json
```

Жинау (build) қажет емес: бұл дайын статикалық сайт және екі сервер функциясы.

## Vercel-ге жүктеу

### 1-тәсіл: GitHub арқылы (ең оңайы)

1. github.com сайтында жаңа репозиторий ашыңыз (**New repository**, мысалы `zhapyraqscan-ai`).
2. **Add file → Upload files** батырмасын басып, осы бумадағы **барлық файлдар мен `api` папкасын** сүйреп тастаңыз («choose your files» папканы таңдай алмайды). `index.html` репозиторийдің ең жоғарғы деңгейінде, `analyze.js` пен `status.js` міндетті түрде `api` папкасында тұруы керек. **Commit changes** басыңыз.
3. vercel.com сайтына GitHub аккаунтыңызбен кіріңіз → **Add New… → Project** → репозиторийді таңдап **Import**.
4. Framework Preset — **Other**, Build Command мен Output Directory бос қалады. **Deploy** басыңыз.
5. 1 минуттан кейін сайт `https://сіздің-жоба.vercel.app` мекенжайында ашылады.

### 2-тәсіл: Vercel CLI арқылы

```bash
npm i -g vercel
cd zhapyraqscan-ai
vercel          # алғашқы жүктеу
vercel --prod   # негізгі мекенжайға шығару
```

## AI көру модулін қосу (өсімдік түрін тану үшін қажет)

Кілтсіз де түс индикаторы, анықтағыш, анықтамалық пен журнал жұмыс істейді. Бірақ өсімдік түрін суреттен автоматты тану үшін кемінде бір кілт керек. Екеуі де тегін.

**Google Gemini (негізгі):**
1. https://aistudio.google.com сайтына Google аккаунтымен кіріп, **Get API key → Create API key** басыңыз.
2. Vercel → жоба → **Settings → Environment Variables** → Name: `GEMINI_API_KEY`, Value: кілт → **Save**.

**Pl@ntNet (қосымша, ботаникалық түр анықтау):**
1. https://my.plantnet.org сайтында тіркеліп, жеке кабинеттен API кілтін көшіріңіз (тегін, күніне 500 сұраныс).
2. Vercel-ге `PLANTNET_API_KEY` атымен қосыңыз.

Кілттерді қосқан соң **Deployments** бөлімінде соңғы жүктеудің мәзірінен **Redeploy** басыңыз. Сайтта «AI көру модулі» жанында «қосылған: Google Gemini + Pl@ntNet» деген жазу шығады.

Қосымша айнымалылар (қажет болса): `GEMINI_MODEL` (модель атауы), `ANTHROPIC_API_KEY` және `CLAUDE_MODEL` (Gemini орнына Claude моделі).

Кілт тек серверде сақталады, сайттың кодында көрінбейді. Кілтті ешкімге көрсетпеңіз.

## Жақсы сурет түсіру ережесі

1. Жапырақты ақ қағаздың үстіне қойыңыз немесе қолмен ұстаңыз, фон бір түсті болсын.
2. Күндізгі шашыраңқы жарықта, тікелей күн сәулесінсіз түсіріңіз.
3. Жапырақ кадрдың 50–80%-ын алсын, фокус анық болсын.
4. Жапырақтың үстін де, астын да түсіріңіз: кейбір аурулардың өңезі тек астында көрінеді.
5. Бір өсімдікті әр 3–7 күн сайын тексеріп, журналға бір белгімен (мысалы, «Қызанақ №1») сақтаңыз.

## Тексеру нәтижелері (2.2-нұсқа)

- Платформаны жасау мен тексеруге 9 074 сурет пайдаланылды: PlantVillage (6 496) және PlantDoc (2 578).
- Нәтижелер ауру мен сау жапырақтардың суреттері бойынша есептелді.
- Баптауға қатыспаған 462 нақты фотода түс индикаторы сау жапырақтардың 86,1%-ын сау деп таныды (1-нұсқада 7,3%), ауру жапырақтардың 77,4%-ында мәселе байқады.
- Ешқашан көрмеген 5 397 PlantVillage фотосында: сезімталдық 77,9%, ерекшелік 83,9%.
- 880 синтетикалық суретте: айқын белгілер 94,5%, ерте саты 82,3%, нашар сурет 88,2%, ерте саты мен нашар сурет 80,0%.

## Салыстырмалы зерттеу («Салыстыру» беті)

Мамандар белгілеген 100 сурет (PlantVillage 50, PlantDoc 50; `test_images.js`) бойынша үш тәсіл салыстырылады:
1. **Көзбен бағалау** – оқушы немесе мұғалім әр суретке өсімдік түрі мен жағдайын таңдайды (дұрыс жауап көрсетілмейді).
2. **Түс индикаторы** – бір батырмамен 100 сурет телефонда талданады.
3. **AI көру модулі** – әр сурет AI-ға «соқыр» түрде жіберіледі (GEMINI_API_KEY керек, 10–15 минут).
Нәтижелер бетінде дәлдік, Коэн каппасы, кесте, диаграмма, CSV және жобаға қоюға дайын мәтін шығады.

## Компьютерде ашу

`index.html` файлын браузерде ашсаңыз да түс индикаторы, анықтағыш және анықтамалық жұмыс істейді (AI көру модулі мен Уикипедия суреттері тек сайт интернетте ашылғанда жүктеледі).

## Ескерту

Платформа – оқу-зерттеу құралы. Нақты диагнозды агроном немесе фитосанитарлық зертхана қояды. Шегіртке, бактериялық күйік сияқты карантиндік қауіп байқалса, аудандық фитосанитарлық инспекцияға хабарлаңыз. Химиялық препаратпен тек ересектер жұмыс істейді.
